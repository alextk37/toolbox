# tmux config — Nord-тема, vi-клавиши, быстрые биндинги

Минималистичный конфиг для tmux 3.4+. Тёмная Nord-тема, vi-style copy mode, умная навигация по панелям.

## Установка

```bash
cp tmux.conf ~/.tmux.conf
tmux source-file ~/.tmux.conf
```

Или симлинк (чтобы обновления из репо подхватывались автоматом):

```bash
ln -sf $(pwd)/tmux.conf ~/.tmux.conf
```

## Что внутри

### Управление панелями

| Сочетание | Действие |
|---|---|
| `\|` | Разделить вертикально |
| `-` | Разделить горизонтально |
| `Alt + ←↑↓→` | Переход между панелями |
| `Alt + Shift + ←→` | Изменить ширину панели |
| `Alt + Shift + ↑↓` | Изменить высоту панели |
| `m` | Развернуть/свернуть панель |
| `x` | Закрыть панель |
| `Tab` | Переключить на предыдущую панель |

### Окна и сессии

| Сочетание | Действие |
|---|---|
| `Ctrl-f` | Дерево сессий |
| `r` | Перезагрузить конфиг |

### Copy mode (vi)

| Сочетание | Действие |
|---|---|
| `v` | Начать выделение |
| `Ctrl-v` | Прямоугольное выделение |
| `y` | Скопировать и выйти |

### Внешний вид

- Nord-тема (тёмная палитра: `#2e3440` фон, `#88c0d8` акцент)
- Нумерация окон и панелей с 1
- Часы и дата в статус-баре
- 50 000 строк истории

### Терминал

- True Color (24-bit) включён
- Escape-time 10 мс (без задержек в Vim/Neovim)
- Фокус-события пробрасываются
