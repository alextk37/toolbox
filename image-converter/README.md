# Конвертер изображений → JPEG

Конвертирует изображения любых форматов (включая HEIC с iPhone) в JPEG максимального качества.
JPEG-файлы копируются без перекодировки — все исходники оказываются в выходной папке.

## Установка

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
```

Три библиотеки: **Pillow** (работа с изображениями), **pillow-heif** (поддержка HEIC), **rich** (красивый CLI).

## Использование

```bash
python3 convert.py                          # input_images → output_images
python3 convert.py -i ./фото -o ./jpg       # свои папки
python3 convert.py -r                       # рекурсивно (вложенные папки)
python3 convert.py -q 95                    # качество JPEG 95 вместо 100
python3 convert.py -n                       # dry-run — только посмотреть
python3 convert.py -d -y                    # конвертировать и удалить исходники
```

По умолчанию скрипт ищет изображения в `./input_images` и сохраняет результат в `./output_images`.
Выходная папка создаётся автоматически. Если входной папки нет — Rich показывает сообщение с подсказкой.

## Что делает с каждым типом файлов

| Тип | Действие |
|---|---|
| HEIC, PNG, WEBP, TIFF, BMP, AVIF, GIF, ICO, PSD, TGA, SVG, EPS и др. | Конвертирует в JPEG (quality=100, 4:4:4) |
| JPEG (.jpg, .jpeg, .jfif) | Копирует без перекодировки (shutil.copy2) |

## Особенности

- Обрабатывает файлы **строго по одному** — не перегружает ОЗУ
- **JPEG quality=100 + subsampling=0** (4:4:4, без потери цветности)
- JPEG-файлы копируются побайтово (быстро, без потери качества)
- Прозрачность (PNG RGBA) → белый фон
- При рекурсивном режиме сохраняется структура вложенных папок
- Интерактивный прогресс-бар с оставшимся временем
- Цветная итоговая сводка с разделением на «сконвертировано» и «скопировано»
